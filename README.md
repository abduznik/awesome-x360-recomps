# Awesome Xbox 360 Recomps [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of awesome Xbox 360 game recompilation projects that bring classic titles to modern platforms natively.

Static recompilation translates the original Xbox 360 PowerPC machine code into native C++ that runs on modern hardware — no emulation needed. The result is a native PC build with improved performance, higher resolutions, ultrawide support, and mod capabilities.

## Rexglue

Projects built with the [Rexglue SDK](https://github.com/rexglue/rexglue-sdk).

| Game | Description | Author |
|------|-------------|--------|
| [Skate 3](https://github.com/mchughalex/skate3recomp) | Native recompilation of Skate 3 for Windows, Linux, and macOS — runs at 4K 165fps with ultrawide support. | [mchughalex](https://github.com/mchughalex) |
| [Naughty Bear](https://github.com/MaxDeadBear/NaughtyBear_ReStuff) | PC port of Naughty Bear Gold Edition (all DLC included) for Windows. | [MaxDeadBear](https://github.com/MaxDeadBear) |
| [Lollipop Chainsaw](https://github.com/MaxDeadBear/Re-Cherry) | PC port of Lollipop Chainsaw for Windows. | [MaxDeadBear](https://github.com/MaxDeadBear) |
| [Banjo-Kazooie: Nuts & Bolts](https://github.com/masterspike52/reNut) | Recompilation of Banjo-Kazooie: Nuts & Bolts for Windows and Linux, runnable via the Goopie launcher. | [masterspike52](https://github.com/masterspike52) |
| [Viva Piñata: Trouble in Paradise](https://github.com/SolarCookies/TiP-Recomp) | Early-stage recompilation of Viva Piñata: Trouble in Paradise with mod support via function hooking, targeting Windows (Linux planned). | [SolarCookies](https://github.com/SolarCookies) |
| [GoldenEye 007](https://github.com/SunJaycy/GoldenEye-Recomp) | Native PC port of the Xbox 360 version of GoldenEye 007, statically recompiled with the ReXGlue SDK. | [SunJaycy](https://github.com/SunJaycy) |
| [Blue Dragon (re:Blue)](https://github.com/zolaware/reblue) | Native recompilation of Blue Dragon, rebuilding the game as a PC application rather than emulating a console around it. | [zolaware](https://github.com/zolaware) |
| [Lost Odyssey](https://github.com/freefrank/LostOdysseyRecomp) | Experimental native PC port of Lost Odyssey using static recompilation; no game assets included. | [freefrank](https://github.com/freefrank) |
| [Ninja Gaiden II](https://github.com/TheSaltTrader/Ninja-s-Dawn---A-Ninja-Gaiden-2-Recompilation-Project) | "Ninja's Dawn" — recompilation of Ninja Gaiden II for native Windows. | [TheSaltTrader](https://github.com/TheSaltTrader) |
| [Ace Combat 6: Fires of Liberation](https://github.com/sal063/AC6_recomp) | Native PC port of Ace Combat 6, statically recompiling the Xbox 360 PowerPC code to x86-64. | [sal063](https://github.com/sal063) |
| [Crackdown](https://github.com/SkiddyToast/Crackdown) | Recompilation of the original Crackdown to native Windows. | [SkiddyToast](https://github.com/SkiddyToast) |
| [Crackdown 2](https://github.com/matty45/Crackdown2-Recomp) | Bare-bones static recompilation of Crackdown 2; reaches in-game but not yet fully playable. | [matty45](https://github.com/matty45) |
| [Dante's Inferno](https://github.com/florinp93/hells-gate-recomp) | Xbox 360 to PC port of Dante's Inferno via static recompilation. | [florinp93](https://github.com/florinp93) |
| [Castlevania: Symphony of the Night (XBLA)](https://github.com/birabittoh/NocturneRecomp) | Static recompilation of the Xbox Live Arcade release of Castlevania: Symphony of the Night, for Windows and Linux. | [birabittoh](https://github.com/birabittoh) |
| [Fable II](https://github.com/Fable2Recomp/Fable2Recomp) | Recompilation of Fable II (GOTY TU1), streamlining and fixing issues from the base ReXGlue approach. | [Fable2Recomp](https://github.com/Fable2Recomp) |
| [Project Gotham Racing 4](https://github.com/beatrixzy/PGR4-Recomp) | Native x86-64 port of Project Gotham Racing 4. | [beatrixzy](https://github.com/beatrixzy) |
| [DoDonPachi SaiDaiOuJou](https://github.com/eandis/SDOJ-Recomp) | Recompilation of the Xbox 360 shmup DoDonPachi SaiDaiOuJou. | [eandis](https://github.com/eandis) |
| [Silent Hill: Downpour](https://github.com/LittleBitUA/DownpourRecomp) | Native Windows port of Silent Hill: Downpour running at unlocked 60 FPS with mouse/keyboard support. | [LittleBitUA](https://github.com/LittleBitUA) |
| [Daytona USA (XBLA)](https://github.com/Subarasheese/daytona-xbla-recomp) | Recompilation of the Xbox Live Arcade release of Daytona USA. | [Subarasheese](https://github.com/Subarasheese) |
| [Condemned 2: Bloodshot](https://github.com/psxrestore/Condemned2Recomp) | Static recompilation of Condemned 2: Bloodshot. | [psxrestore](https://github.com/psxrestore) |
| [Dragon Ball Z: Budokai HD Collection](https://github.com/WistfulHopes/DBZ1) | Recompilation of Dragon Ball Z: Budokai HD Collection. | [WistfulHopes](https://github.com/WistfulHopes) |
| [Dragon Ball: Raging Blast 2](https://github.com/WistfulHopes/RB2) | Recompilation of Dragon Ball: Raging Blast 2. | [WistfulHopes](https://github.com/WistfulHopes) |
| [Halo 3 (cache build)](https://github.com/twist84/halo3_cache_release_recomp) | Early technical recompilation of a leaked Halo 3 March 2007 delta build; not a playable release. | [twist84](https://github.com/twist84) |

## XenonRecomp

Projects built with [XenonRecomp](https://github.com/hedge-dev/XenonRecomp) (PowerPC → C++) and [XenosRecomp](https://github.com/hedge-dev/XenosRecomp) (Xenos shaders → HLSL).

| Game | Description | Author |
|------|-------------|--------|
| [Sonic Unleashed](https://github.com/hedge-dev/UnleashedRecomp) | Unofficial PC port of Sonic Unleashed for Windows and Linux — supports high resolutions, ultrawide, high framerates, and mods via Hedge Mod Manager. | [hedge-dev](https://github.com/hedge-dev) |
| [Sonic the Hedgehog (2006)](https://github.com/sonicnext-dev/MarathonRecomp) | Unofficial PC port of Sonic '06 for Windows, Linux, and macOS — still in active development. | [sonicnext-dev](https://github.com/sonicnext-dev) |
| [GoldenEye 007 Remastered (XBLA)](https://github.com/Fable2Recomp/beanRecomp) | Static recompilation ("BeanRecomp") of the GoldenEye 007 Remastered Xbox Live Arcade release. | [Fable2Recomp](https://github.com/Fable2Recomp) |
| [The Simpsons Game](https://github.com/YesterMester/TheSimpsonsGameRecomp) | Recompilation of The Simpsons Game (2007), combining a XenonRecomp-style translation approach with a Xenia-derived runtime. | [YesterMester](https://github.com/YesterMester) |
| [Skate 2](https://github.com/Skate-2-Team/sk82-recomp) | Recompilation of Skate 2. Archived and no longer in active development as of 2026-07-29. | [Skate-2-Team](https://github.com/Skate-2-Team) |
| [Test Drive Unlimited](https://github.com/testdriveupgrade/TDURecomp) | Very early native port of Test Drive Unlimited, built on a custom XenonRecomp fork tailored to the TDU engine. | [testdriveupgrade](https://github.com/testdriveupgrade) |
